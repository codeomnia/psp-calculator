Нормативы по ПСП и ГДЗСУПО ГУпЧС МВД ПМР · Приказ № 22 от 03.04.2019

Результат

Как считается оценка

Время в приказе задано для личного состава до 30 лет, летом, на асфальте. Для других условий исходное время умножается на поправочные коэффициенты; при нескольких факторах коэффициенты перемножаются последовательно. Нормативы по ГДЗС выполняются в СИЗОД, поэтому коэффициент Ку «с защитой органов дыхания» для них не применяется.

Оценка по времени: уложились в норму «отлично» — отлично; в «хорошо» — хорошо; в «удовлетворительно» — удовлетворительно; иначе неудовлетворительно. Если норматив выполняется несколько раз (не более трёх), оценка ставится по последнему результату. Любая ошибка, способная привести к травме или повреждению снаряжения, — «неудовлетворительно».

Оценка за несколько нормативов (п. 3.3)

  • Отлично — более половины нормативов на «отлично», остальные на «хорошо».
  • Хорошо — более половины не ниже «хорошо», остальные на «удовлетворительно».
  • Удовлетворительно — не менее 70 % нормативов выполнены; при трёх нормативах достаточно двух, один из них не ниже «хорошо».

Оценка отделению, караулу (п. 3.4, 3.5)

  • Отлично — все получили положительные оценки, более 50 % на «отлично».
  • Хорошо — все положительные, более 50 % не ниже «хорошо».
  • Удовлетворительно — не менее 90 % положительных оценок.
  • Общая оценка подразделению выводится из двух оценок: за нормативы в составе отделения (караула) и за индивидуальные.

Обязательные нормативы

№ 1, 4, 11, 19, 20, 26, 32 — при инспектировании, итоговых проверках и контрольных занятиях.

О данных в приложении

  • Времена, условия и коэффициенты взяты из сборника без изменений.
  • У нормативов № 25–38 в тексте сборника нет названий (они есть только на схемах), поэтому названия составлены по условиям выполнения.
  • Знак ⚠ отмечает значения, которые выбиваются из ряда или совпадают в исходной таблице. Сверьте их с оригиналом приказа.
  • Надбавки за расположение всасывающего патрубка прибавляются к исходной норме до умножения на коэффициенты; порядок в приказе не уточнён.
