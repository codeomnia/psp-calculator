# Калькулятор нормативов ПСП и ГДЗС

Веб-приложение по сборнику нормативов УПО ГУпЧС МВД ПМР (Приказ № 22 от 03.04.2019).

## Возможности
- Расчёт оценки с учётом возрастного коэффициента (Кв) и других поправок (Кс, Кт, Ку)
- Описание условий выполнения каждого норматива
- Светлая / тёмная тема
- Список нормативов ПСП и ГДЗС с поиском

## Открыть
Откройте `index.html` в браузере или сайт на Cloudflare Pages после деплоя.

Служебное использование.
